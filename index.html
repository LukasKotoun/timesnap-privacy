TimeSnap – Privacy Policy

Effective date: 26 November 2026

1. Scope

This Privacy Policy sets out how personal data is processed in connection with the use of the TimeSnap mobile application for Android (the "Application"). It applies to every version of the Application, whether obtained through Google Play or installed directly from an installation package. By using the Application, the user acknowledges the processing described below.

2. Controller and contact

The Application is developed by the TimeSnap development team as a student project at the Faculty of Information Technology, Brno University of Technology, Czech Republic (the "Developer"). Questions and requests concerning personal data may be sent to xkotou08@vutbr.cz.

3. Data stored on the user's device

The following data is created by the user and stored solely in the local storage of the user's device:

  • time entries, categories, daily goals, items awaiting resolution, saved AI examples and application settings;
  • for each voice recording, the resulting transcript and the response of the language model;
  • the user's own Groq API key, if provided, which is stored in encrypted form and excluded from any backup.

The Developer operates no server and has no access to this data. Where the user has enabled Android backup, the operating system may include this data (with the exception of the API key) in the user's device backup under the terms of Google. Exports and backups created within the Application are saved only to a location selected by the user.

4. Voice recordings and transmission to Groq

Audio is recorded only upon an explicit action of the user (activation of a microphone control in the Application, its notification or its widget). To convert a recording into time entries, the Application transmits:

  • the audio recording to Groq, Inc. (United States) for speech-to-text conversion; and
  • the resulting transcript to the language model service of Groq, Inc., together with the context necessary for its interpretation: the date and time of the recording, the user's category names and voice keywords, recently used activity names, the entries of the day concerned and the user's saved AI examples.

All transmissions are encrypted (HTTPS). The audio file is deleted from the device once it has been processed; where no internet connection is available, it is retained on the device only until it can be transmitted. Groq, Inc. processes the transmitted data in accordance with its Privacy Policy. As Groq, Inc. is established in the United States, the data may be processed outside the European Economic Area.

5. Weekly summary

Where the user has entered their own Groq API key, the Application transmits once a week an aggregated summary of the preceding week to Groq, Inc. in order to generate suggestions: time per category, unlogged time, the most frequent activities and the user's goals. No such summary is transmitted without the user's own API key.

6. Device usage data

If the user enables the "Show screen time" option and grants usage access, the Application reads the periods during which the device screen was switched on, solely in order to display them in the Application. This data is never transmitted from the device.

7. Permissions

The Application requests the microphone permission (voice recording), the notification permission (reminders and quick capture) and, optionally, usage access (Section 6). Each permission may be withdrawn at any time in the Android settings.

8. Legal basis

Voice recordings are processed on the basis of the user's consent, expressed by starting each recording (Article 6(1)(a) GDPR), and to the extent necessary to provide the functions requested by the user (Article 6(1)(b) GDPR). The Application does not use personal data for advertising, analytics or profiling, and personal data is not sold.

9. Retention and deletion

Data stored on the device is retained until the user deletes it. Individual entries may be deleted within the Application; all data is erased by uninstalling the Application or by clearing its storage in the Android settings.

10. Rights of the user

The user has the right to request access to, rectification or erasure of personal data, restriction of its processing and data portability, and the right to object, to the extent provided by the General Data Protection Regulation. As the Developer holds no personal data of users, most of these rights are exercised directly within the Application. The user may lodge a complaint with the Office for Personal Data Protection (Úřad pro ochranu osobních údajů, uoou.gov.cz).

11. Children

The Application is not directed at children under the age of 13.

12. Changes to this Policy

The Developer may amend this Privacy Policy. Any amended version will be published on this page together with its effective date.
